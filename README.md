# Torque &amp; Tread — Motorcycle Service &amp; Repair Shop Template

A complete, premium HTML5 website template for a motorcycle service and repair
workshop, built with **Bootstrap 5**, clean CSS3, and vanilla JavaScript. No
Tailwind, no React/Vue/Angular, no build step required.

## Highlights

- 11 fully responsive pages with unique layouts and a shared design system,
  including two alternate homepage layouts (`index.html` and `home-v2.html`)
- Light / dark mode with saved preference (`localStorage`)
- RTL (right-to-left) stylesheet for Arabic, Hebrew and other RTL locales
- Accessible: semantic HTML, keyboard navigation, visible focus states, ARIA labels
- Client-side form validation (no browser `alert()`s)
- SEO meta tags, Open Graph tags, JSON-LD structured data, sitemap.xml, robots.txt
- Custom SVG illustrations throughout — no external image licensing to manage
- Zero dependencies beyond Bootstrap 5 (CDN) and Google Fonts

## Quick Start

See `documentation/installation-guide.md` to get the template running locally
or on a host, and `documentation/customization-guide.md` to make it your own.
